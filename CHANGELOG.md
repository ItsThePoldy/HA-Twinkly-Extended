# Changelog

All notable changes to this project are documented here. Versions follow
[Semantic Versioning](https://semver.org/); `0.x` releases may change behaviour
between minor versions.

## [Unreleased]

### Added
- Predefined device effects (`effect` mode) in the light's effect list, after
  the movies. Names come from `effect_names.yaml`, one rule per device variant;
  effects of a device without a rule are listed as `Effect <n>`. Movie entries
  keep their `"<id> <name>"` form, so existing automations are unaffected.
- Diagnostics include the device's predefined effect ids and resolved names.
- Rule for the Twinkly Curtain 210 RGBW (`TWW210SPP2`).
- Packaging of the core Twinkly integration (Home Assistant 2026.10.2) as a
  HACS custom integration: manifest `version`, committed `translations/en.json`
  (generated by `script/gen_translations.py`), test suite running on
  `pytest-homeassistant-custom-component`.
- Brand assets in `custom_components/twinkly/brand/`, taken from the
  Home Assistant brands repository's `core_integrations/twinkly`.

### Changed
- `ttls` is required as `>=1.11.1` instead of pinned, so it follows the version
  Home Assistant itself installs.
